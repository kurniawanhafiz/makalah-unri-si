# Template prompt makalah (tanpa skill)

Salin, isi bagian [ ... ], lalu kirim ke Claude. Bila skill makalah-unri-si sudah terpasang, cukup tulis bagian "Data makalah" saja.

---

Buatkan makalah dalam format .docx dengan ketentuan berikut.

**Format**
- Kertas A4, margin 4-3-3-3 (kiri 4 cm, atas 3, kanan 3, bawah 3), Times New Roman 12, spasi 1,5, rata kiri-kanan.
- Urutan: cover, daftar isi (otomatis), kata pengantar, Bab I Pendahuluan, Bab II Pembahasan, Bab III Penutup, daftar pustaka.
- Cover (font 14): judul makalah, logo [UNRI, saya unggah / sudah ada di skill], "Disusun untuk memenuhi tugas mata kuliah [mata kuliah]", "Dosen Pengampu: [nama dosen]", "Disusun oleh:" [jumlah] orang beserta NIM (placeholder, saya edit sendiri), lalu [UNIVERSITAS], [tahun].
- Cover dihitung halaman i tetapi nomornya disembunyikan (beda section). Daftar isi dan kata pengantar bernomor romawi di tengah bawah. Bab I sampai III bernomor angka mulai 1 di kanan bawah. Daftar pustaka tanpa nomor yang terlihat.
- Penomoran heading 1.1, 1.2, 2.1, dan seterusnya. Paragraf di bawah subbab sejajar dengan tulisan subbab (bukan angkanya), baris pertama tetap menjorok.
- Hindari tabel. Satu tabel boleh bila memang perlu.

**Isi**
- Kata pengantar standar. Bab I berisi latar belakang, rumusan masalah, tujuan, manfaat. Bab III berisi kesimpulan dan saran.
- Bab II memakai kutipan (parafrase) dari referensi di setiap subbab, ditambah contoh bila ada. Contoh rekaan diberi label.
- Daftar pustaka gaya APA 7 dengan link DOI. Hanya sumber yang benar-benar terverifikasi. Kalau ada sumber saya yang tidak bisa dibuka atau tidak relevan, jangan dipakai dan beri tahu alasannya.
- Bahasa baku dan natural, tanpa tanda pisah panjang, tanpa gaya kalimat khas AI.
- Sebelum membuat, boleh tanya dulu bila ada yang belum jelas.

**Data makalah**
- Judul: [ ... ]
- Mata kuliah: [ ... ]
- Dosen pengampu: [ ... ]
- Jumlah anggota: [ ... ]
- Materi / poin bahasan:
  - [ ... ]
  - [ ... ]
- Referensi dari saya (boleh ditambah yang valid):
  - [DOI / link / PDF yang saya unggah]
